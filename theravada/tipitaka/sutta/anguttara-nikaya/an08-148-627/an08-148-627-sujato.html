Numbered Discourses 8.148–627
11. Abbreviated Texts Beginning With Greed
Untitled Discourses on Hate, Etc.
“For insight into hate … delusion … anger … acrimony … disdain … contempt … jealousy … stinginess … deceitfulness … deviousness … obstinacy … aggression … conceit … arrogance … vanity …
For insight into negligence … complete understanding … complete ending … giving up … ending … vanishing … fading away … cessation … giving away … For the letting go of negligence these eight things should be developed.”
The Book of the Eights is finished.
