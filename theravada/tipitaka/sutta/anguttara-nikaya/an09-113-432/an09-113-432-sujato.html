Numbered Discourses 9.113–432
10. Abbreviated Texts Beginning with Greed
Untitled Discourses on Hate, Etc.
“For insight into hate … delusion … anger … acrimony … disdain … contempt … jealousy … stinginess … deceitfulness … deviousness … obstinacy … aggression … conceit … arrogance … vanity …
For insight into negligence … complete understanding … complete ending … giving up … ending … vanishing … fading away … ceasing … giving away … For the letting go of negligence … these nine things should be developed.”
The Book of the Nines is finished.
